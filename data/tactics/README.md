# 戦術データ（編成チェッカー用）

ブキごとの戦術パラメータを運営が入力する表です。3 つの CSV に分かれています。

| ファイル | 行 | 入力する列 |
| --- | --- | --- |
| `mains.csv` | メイン性能ごと（65）。同じメインのブキ（例: スプラシューター / コラボ / 煌）は共通 | ポジション、有効射程、塗り拡張、瞬間塗り、キル、エリア関与、ヤグラ関与、ホコ関与、アサリ関与 |
| `kits.csv` | ブキ（メイン＋サブ＋スペシャル）ごと（160） | 打開力、タグ、略称 |
| `specials.csv` | スペシャルごと（19） | 分類 |

- 「（参考）」の列は自動で埋まる列です。入力しなくてかまいません（`tactics:sync` で毎回上書きされます）。
- レプリカ（ヒーロー・オクタ・オーダー・PET）は元のブキの値を使うので、行はありません。
- **空欄は「未入力」**として扱い、編成チェッカーはその項目を数えません。よく使うブキから順に埋めていけます。

## 値の決まり

| 列 | 値 |
| --- | --- |
| ポジション | `前衛` / `中衛` / `後衛` / `サポート` |
| 有効射程 | 試し撃ち場のライン本数（有効射程）。0.1 刻み（例: `2.5`） |
| 塗り拡張 | 1〜5。時間あたりに広く塗る力（エリア確保・スペシャル回転） |
| 瞬間塗り | 1〜5。対面中に足場を作る・相手の足場を奪う力 |
| キル | 1〜5。キル・対面力 |
| エリア / ヤグラ / ホコ / アサリ関与 | 1〜5。そのルールのオブジェクトに関わる適性（エリア維持・ヤグラ乗り・ホコ持ち / 割り・アサリ運び） |
| 打開力 | 1〜5。メイン＋サブ・スペシャルの総合 |
| タグ | 次から選び、複数は `/` で区切る: `曲射` `ボム持ち` `機動力高` `潜伏` `ホコ割り強` `塗り広げ` `索敵` `防御` `長射程牽制` |
| 略称 | 8 文字まで。編成名（Discord 用コピー）に使う。空欄なら正式名 |
| 分類（スペシャル） | `打開・起点` / `抑え・遅延` / `エリア確保` / `敵を動かす` |

1〜5 の評価は、段階ごとに基準のブキを決めておくとぶれにくくなります（例: 塗り拡張 3 ＝ スプラシューター）。

## 入力の流れ

1. CSV を Google スプレッドシートで開く（ファイル → インポート）か、Excel で開く
2. 値を入力する
3. CSV で書き出して、同じ名前で上書きする
   - Google スプレッドシート: ファイル → ダウンロード → カンマ区切り形式（.csv）
   - Excel: 「CSV UTF-8（コンマ区切り）」で保存する（ただの「CSV」だと文字化けします）
4. `npm run tactics:check` で検証する。問題があれば、どのファイルのどのブキのどの列かが表示されます
   - 問題がなければ `src/data/tactics.json` が更新されます。ビルド（`npm run build`）でも自動で検証され、問題があるとビルドが止まります

新ブキが追加されたら、ブキデータを更新したあとに `npm run tactics:sync` を実行すると、足りない行が追加されます（入力済みの値はそのまま残ります）。

開発者に頼む場合は、書き出した CSV をそのまま渡してもらえれば反映します。
